How data enters

Each outside system has a Source in fetch/<domain>/. A Source asks the system for data and returns it without parsing it. Every Low-tier fetch lands in the raw schema. horizon keeps each version of a record and never prunes it (decision 0002, as amended on 2026-10-05). Readers in read/ turn pages and files into text, and dbt builds the marts that the app and the tools read.

Every schedule in the code ships stopped. The operator starts it on the production instance. The cadence column therefore says what the code declares, and not what runs today. Times are America/New_York.

The module paths in the tables below are under backend/src/pipeline/.
